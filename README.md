# MotorMind — EEG Motor Imagery Classification

MotorMind is a machine-learning project exploring EEG-based classification of imagined left-hand and right-hand movements.

## Current work

- Raw EEG recording and annotation inspection
- EEG preprocessing and frequency filtering
- Motor-area channel selection and trial extraction
- Signal-quality checks and visualization
- Baseline CSP + LDA model evaluation

## Dataset

This project uses the PhysioNet EEG Motor Movement/Imagery Dataset.

Raw EEG recordings and generated numerical epoch arrays are excluded from this repository. See the dataset documentation and project scripts for information about obtaining and processing the data.

## Status

Research and development in progress. Model results should be interpreted in the context of the evaluation protocol and dataset limitations.
